# AI编程手册

## 根指令
1. AI编程时必须首先阅读此文件夹中的指令，并严格遵照执行
2. AI运行时如果需要修改加载器以及其他属于框架变动的事情，必须先生成MD文档并询问人类建议

## AI路由法则
### 路由编写规则
1. 编写路由时参考 doc 文件夹中有关路由的部分
2. 编写的路由必须在路由位置创建同名md文件
3. 文件中简要说明路由的输入格式、输出格式以及运行原理和内容
4. 如果修改某个路由js文件，必须处理相应的md文件
5. 如果修改的路由文件涉及到其他文件的变动，必须检查并修改其他文件
6. 修改路由时尽可能不要更改输入输出格式，如果必须修改，需要先判断这个格式修改会牵涉到哪些前后端更改，例如public中的前端页面

### 同名MD文件规则
- 前面部分：接口的叙述（已有的内容）
- 后面部分：记录所有调用这个路由的位置，方便修改路由时检查并修改全部相关内容
