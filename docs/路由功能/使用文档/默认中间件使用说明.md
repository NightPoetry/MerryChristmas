
# 🔧 中间件使用说明

本项目包含多个预置中间件，默认部分启用，部分禁用。

---

## 📋 中间件列表

### ✅ 默认启用

| 中间件 | Order | 说明 |
|--------|-------|------|
| `requestId.js` | 0 | 生成请求唯一 ID |
| `logger.js` | 1 | 记录请求日志 |
| `cors.js` | 10 | 处理跨域 |
| `securityHeaders.js` | 11 | 设置安全响应头 |
| `compression.js` | -3 | 响应压缩 |
| `responseFormatter.js` | -2 | 统一响应格式 |
| `errorHandler.js` | -1 | 错误处理 |

### 🔒 默认禁用（需要时启用）

| 中间件 | Order | 说明 | 启用方法 |
|--------|-------|------|---------|
| `rateLimit.js` | 20 | API 限流 | 设置 `enabled: true` |
| `jwtAuth.js` | 40 | JWT 验证 | 设置 `enabled: true` |
| `bodyValidator.js` | 45 | 请求体验证 | 设置 `enabled: true` |
| `authorization.js` | 50 | 权限验证 | 设置 `enabled: true` |
| `transaction.js` | 60 | 数据库事务 | 设置 `enabled: true` |
| `cache.js` | 30 | 响应缓存 | 设置 `enabled: true` |
| `audit.js` | 2 | 审计日志 | 设置 `enabled: true` |
| `performance.js` | 1 | 性能监控 | 设置 `enabled: true` |
| `ipWhitelist.js` | 5 | IP 白名单 | 设置 `enabled: true` |

## 🚀 快速启用中间件

### 方法 1：修改中间件文件

编辑中间件文件，将 `enabled` 设置为 `true`：

```javascript
const config = {
  level: ['protected'],
  order: 40,
  enabled: true,  // ✅ 改为 true
  description: 'JWT 身份验证'
};
```

### 方法 2：环境变量控制（推荐）

在中间件中添加环境变量支持：

```javascript
const config = {
  level: ['protected'],
  order: 40,
  enabled: process.env.ENABLE_JWT_AUTH === 'true',
  description: 'JWT 身份验证'
};
```

然后在 `.env` 中配置：

```env
ENABLE_JWT_AUTH=true
```

## 🔧 中间件配置示例

### JWT 认证 + 权限验证

1. 启用 `jwtAuth.js`：

```javascript
const config = {
  level: ['protected'],
  order: 40,
  enabled: true,  // ✅
  exclude: ['/auth/refresh']
};
```

2. 启用 `authorization.js`：

```javascript
const config = {
  level: ['protected'],
  order: 50,
  enabled: true  // ✅
};
```

3. 在路由中使用：

```javascript
const config = {
  method: 'POST',
  requireRoles: ['admin'],
  requirePermissions: ['users.delete']
};

function deleteUser(ctx) {
  // 只有 admin 角色且拥有 users.delete 权限的用户可以访问
}
```

---

### 限流保护

1. 启用 `rateLimit.js`：

```javascript
const config = {
  level: ['public', 'protected'],
  order: 20,
  enabled: true  // ✅
};
```

2. 在路由中配置限流：

```javascript
const config = {
  method: 'POST',
  rateLimit: {
    max: 10,           // 10次请求
    windowMs: 60000    // 1分钟内
  }
};
```

---

### 数据库事务

1. 启用 `transaction.js`：

```javascript
const config = {
  level: ['protected'],
  order: 60,
  enabled: true  // ✅
};
```

2. 在路由中使用事务：

```javascript
const config = {
  method: 'POST',
  transaction: true  // 启用事务
};

function createPost(ctx) {
  // 使用 ctx.transaction 执行数据库操作
  const result = ctx.transaction.query('INSERT INTO posts ...');
  // 自动提交或回滚
}
```

---

### 审计日志

1. 启用 `audit.js`：

```javascript
const config = {
  level: ['protected'],
  order: 2,
  enabled: true  // ✅
};
```

2. 在路由中启用审计：

```javascript
const config = {
  method: 'DELETE',
  audit: true,
  auditAction: 'DELETE_USER'
};

function deleteUser(ctx) {
  // 操作会被自动记录到审计日志
  // 可以通过 ctx.state.auditChanges 记录变更详情
  ctx.state.auditChanges = {
    userId: 123,
    username: 'john'
  };
}
```

---

## 💡 提示

1. **启动顺序**：`order` 值越小越先执行（负数倒序）
2. **路径排除**：使用 `exclude` 跳过特定路径
3. **层级控制**：通过 `level` 控制中间件作用范围
4. **性能考虑**：只启用必需的中间件
5. **日志查看**：启动时会显示所有已加载的中间件
