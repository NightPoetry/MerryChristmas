# 动态关联型数据库设计文档（精简版）
## 一、核心目标与解决的痛点
### 1.1 核心目标
用「简洁DSL+自动映射+动态关联」，让开发者无需关注底层数据库设计，快速实现实体关联与权限场景。

### 1.2 解决的核心问题
- 无需预先定义实体关系：支持运行时动态绑定（如仓库授权、资源分享），不用改表结构；
- 避免重复数据与同步麻烦：非基本类型自动存ID引用，不冗余存储实体内容；
- 简化关联表设计：自动生成复合主键关联表，无需手动建表；
- 降低开发门槛：读写操作与普通表一致，复合主键无额外学习成本；
- 兼容主流数据库：自动适配MySQL/PostgreSQL/SQLite，无需手动适配语法。

## 二、核心语法规则（DSL）
### 2.1 核心约定
- 实体定义：`实体名{ 字段列表 }`（对应数据库表名小写）；
- 基本类型：`类型:字段名 [属性]`（直接存值），支持`number/str(n)/datetime/bool`；
- 非基本类型：`实体名:字段名`/`实体名[]:字段名`（存储目标实体ID）；
- 主键：显式`number:xxx [primary]`或默认生成`default_id`（自增）。

### 2.2 极简示例（.ais文件）
```ais
# 用户实体（无需标注关联）
User{
    number:user_id [primary]
    str(50):user_name [not null unique]
}

# 仓库实体（无需标注关联）
Warehouse{
    number:warehouse_id [primary]
    str(50):warehouse_name [not null]
}

# 标签实体（被其他实体引用）
Tag{
    number:tag_id [primary]
    str(32):tag_name [not null unique]
}
```

## 三、核心机制
### 3.1 类型驱动存储
- 基本类型：直接存值（如`user_name`存字符串）；
- 非基本类型：仅存主键ID（如`Warehouse:my_warehouse`存`warehouse_id`）。

### 3.2 动态关联规则
- 默认n-n：所有实体关联默认多对多，无需预先标注；
- 自动生成关联表：首次关联时生成`实体1_实体2`表，复合主键（`实体1_id+实体2_id`）+外键约束；
- 关联类型支持：通过`relation_type`字段区分场景（如`owner`/`authorize`）。

### 3.3 关联表示例（自动生成）
```sql
CREATE TABLE user_warehouse (
    user_id INT NOT NULL,
    warehouse_id INT NOT NULL,
    relation_type VARCHAR(32) DEFAULT 'authorize',
    PRIMARY KEY (user_id, warehouse_id), -- 复合主键（防重复）
    FOREIGN KEY (user_id) REFERENCES user(user_id) ON DELETE CASCADE,
    FOREIGN KEY (warehouse_id) REFERENCES warehouse(warehouse_id) ON DELETE CASCADE
);
```

## 四、核心使用示例（JS）
### 4.1 动态授权（仓库授权给用户）
```javascript
// 授权：新增关联关系
async function grantWarehouse(userId, warehouseId) {
    await pool.execute(
        `INSERT INTO user_warehouse (user_id, warehouse_id) VALUES (?, ?)`,
        [userId, warehouseId]
    );
}

// 查询：用户的所有仓库
async function getUserWarehouses(userId) {
    const [rows] = await pool.execute(`
        SELECT w.* FROM warehouse w
        JOIN user_warehouse uw ON w.warehouse_id = uw.warehouse_id
        WHERE uw.user_id = ?
    `, [userId]);
    return rows;
}

// 取消授权：删除关联关系
async function revokeWarehouse(userId, warehouseId) {
    await pool.execute(
        `DELETE FROM user_warehouse WHERE user_id = ? AND warehouse_id = ?`,
        [userId, warehouseId]
    );
}
```

## 五、核心优点
1. 动态灵活：运行时绑定实体，无需预先定义关系，适配授权/分享场景；
2. 自动高效：自动生成主表、关联表（复合主键），无需手动建表；
3. 读写简单：复合主键操作与普通表一致，无额外成本；
4. 数据一致：外键+级联删除，避免脏数据和重复关联；
5. 兼容广泛：支持主流关系数据库，纯JS解析无外部依赖。

## 六、适用场景
- 权限管理（用户-角色-资源授权）；
- 资源分享（仓库、文件、项目多用户共享）；
- 快速原型开发（无需关注数据库设计）；
- 关系频繁变更的灵活业务系统。****
